# 薅羊毛 · Deals Hunter v2

> 搜罗中国主流电商平台（淘宝/天猫、京东、拼多多）的隐藏优惠券、红包口令、百亿补贴、国补等促销信息。

## When to Use

- 用户说"薅羊毛"、"优惠券"、"打折"、"省钱"、"红包"
- 用户问"有什么优惠"、"哪里便宜"
- 用户想买具体品类（手机、家电、美妆、日用、宠物）
- 主动帮用户查当前促销活动

**不要用于：** 查询历史价格走势（不擅长）、比价（仅推荐，不做全面比价）

## 搜索策略（多引擎兜底）

国内电商平台（京东、淘宝、拼多多）和比价网站（什么值得买、慢慢买）都有反爬机制。采用**多引擎轮询 + 多关键词**策略。

### 搜索引擎候选

| 引擎 | 搜索URL | 备注 |
|------|---------|------|
| DuckDuckGo | `https://duckduckgo.com/html/?q=关键词&hl=zh-CN` | 中文结果不稳定 |
| Sogou | `https://www.sogou.com/web?query=关键词` | 中文结果较好，但可能乱码 |
| Bing | `https://www.bing.com/search?q=关键词&setlang=zh-Hans` | 需要合适 UA |

### 搜口令/优惠券

```bash
# DuckDuckGo（首选）
curl -sL "https://duckduckgo.com/html/?q=京东+优惠券+红包口令+2026年8月&hl=zh-CN" \
  -H "User-Agent: Mozilla/5.0" \
  | grep -oP 'uddg=https%3A%2F%2F[^&"]+' \
  | head -5 \
  | python3 -c "
import sys, urllib.parse
seen = set()
for line in sys.stdin:
    url = urllib.parse.unquote(line.strip().replace('uddg=',''))
    if url not in seen:
        seen.add(url)
        print(url)
"

# 搜狗搜优惠（中文结果补充）
curl -sL "https://www.sogou.com/web?query=猫粮+优惠券+2026" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
```

### 搜具体商品好价

```bash
# 搜索"商品名+什么值得买"获取爆料
curl -sL "https://duckduckgo.com/html/?q=什么值得买+阿飞和巴弟+猫粮&hl=zh-CN" \
  -H "User-Agent: Mozilla/5.0"
```

### 提取网页内容（通用方法）

```python
# 抓取并提取文本，去除 script/style 干扰
python3 -c "
import sys, re
html = sys.stdin.read()
html = re.sub(r'<script[^>]*>.*?</script>', '', html, flags=re.DOTALL)
html = re.sub(r'<style[^>]*>.*?</style>', '', html, flags=re.DOTALL)
text = re.sub(r'<[^>]+>', ' ', html)
text = re.sub(r'\s+', ' ', text).strip()
print(text[:2000])
"
```

## 搜索流程

### 步骤1：确认需求
- 用户说"薅羊毛" → 追问想买什么品类
- 用户说具体品类 → 直接搜
- 确认当前是否在大促期间

### 步骤2：搜索最新优惠
```bash
# 按品类搜
curl -sL "https://duckduckgo.com/html/?q=京东+猫粮+优惠券+2026年8月&hl=zh-CN" -H "User-Agent: Mozilla/5.0"

# 搜口令
curl -sL "https://duckduckgo.com/html/?q=京东+红包口令+2026年8月&hl=zh-CN" -H "User-Agent: Mozilla/5.0"
```

### 步骤3：提取信息
从搜索结果中提取：
- 红包口令（如 `福利500`）
- 国补入口（如 `国补004`）
- 品类专属入口（如 `家电006`）
- 活动时间节点

### 步骤4：计算性价比
如果用户提供了价格和规格，计算每公斤价格并评估档次。

### 步骤5：整理输出
按平台分类输出，包括：
- 口令（可直接复制使用）
- 适用平台（淘宝/京东）
- 说明（通用红包/品类补贴）
- 时效性标注

## Common Pitfalls

1. **口令过期** — 电商红包口令有效期短，隔几天就失效。**每次都要重新搜索验证，不要直接用旧数据。**
2. **百度有验证码** — 别用百度搜索，用 `curl + DuckDuckGo` 或搜狗绕过。
3. **Google 拦 curl** — Google 对 curl 的 UA 返回 400，别浪费时间。
4. **京东/淘宝有反爬** — 浏览器访问会跳验证码/login，用 `curl` 搜文章比直接搜商品页面更靠谱。
5. **DuckDuckGo 中文结果不稳定** — 搜不到时换搜狗或 Bing。
6. **用户不说明品类** — 先问清楚想买什么，再针对性搜索，效率更高。
7. **什么值得买有验证码** — 浏览器访问会触发滑块验证，推荐用APP或搜狗搜"什么值得买+商品名"。
