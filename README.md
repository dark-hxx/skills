## 技能列表

| 技能 | 说明 | 适用场景 |
|------|------|----------|
| [deals-hunter](deals-hunter/) | 薅羊毛 · 电商优惠券搜索 | 搜淘宝/京东红包口令、国补、优惠券 |

---

## 使用方法

### Hermes Agent 用户
将技能文件夹复制到 `~/.hermes/skills/` 即可。

### 其他 AI Agent 用户
每个技能目录下都有 `*-prompt.md` 通用提示词文件，直接粘贴给 AI 使用即可。
