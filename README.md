我的 **Hermes Agent** 技能合集，所有 AI Agent 通用。

| 技能 | 说明 | 适用场景 |
|------|------|----------|
| [deals-hunter](deals-hunter/) | 薅羊毛 · 电商优惠券搜索 | 搜淘宝/京东红包口令、国补、优惠券 |

## 使用方法

### Hermes Agent 用户
将技能文件夹复制到 `~/.hermes/skills/` 即可：
```bash
cp -r deals-hunter ~/.hermes/skills/
```

### 其他 AI Agent 用户
每个技能目录下有 `README.md` 通用说明，直接作为提示词喂给 AI 使用。
