# 报价方案兵 · Quote Swarm

> 全流程SOP：户型解析 → 设备识别 → 报价生成 → 方案交付

## 触发词

报价、出方案、报价方案、户型解析、DXF解析、设备识别、点位图、布线图、报价单、弱电报价

## 核心职责

| 职责 | 描述 |
|------|------|
| 户型解析 | DXF/PDF/图片多源输入解析 |
| 设备识别 | AI验图+块提取+文字识别 |
| 方案设计 | 点位规划+布线设计+回路分配 |
| 报价生成 | 自动填充报价表 |
| 方案交付 | HTML报价单+点位图+布线图 |

| 交付物 | 格式 | 命名规范 |
|--------|------|---------|
| HTML报价单 | HTML | 报价_{客户名}_{日期}.html |

| 设备清单 | JSON | 设备_{客户名}_{日期}.json |

## 五步闭环流程

### Phase 1：输入源确认

| 输入类型 | 处理方式 | 输出 |
|---------|---------|------|
| DXF/DWG | ezdxf 解析 | 户型数据（房间、墙体、设备块） |
| JPG/PNG | 可视化分析 | 图像识别结果 |
| 360全景 | 视觉分析 | 照明/布局方案 |
| PDF图册 | 提取文字 | 产品数据 |

### Phase 2：户型解析

1. 解析DXF → 提取房间信息+墙体数据+设备块
2. 识别设备 → 提取设备类型、数量、位置
3. 输出结构化数据（房间信息+设备清单）

### Phase 3：方案设计

1. 点位规划 → 按房间规划设备点位
2. 布线设计 → 设计管线路由+回路分配
3. 电源冗余计算 → 确保≥20%冗余

### Phase 4：报价生成

1. 从设备清单读取设备型号和数量
2. 从价格库查询单价
3. 自动计算总价
4. 生成HTML报价单

**铁律：** 只改数量，不改品名/单价/规格/单位

### Phase 5：方案交付

- HTML报价单（主交付物）
- 点位规划图（设备布局）
- 智能布线图（布线方案）
- 设备清单（JSON数据汇总）

## 质检清单

| 维度 | 检查项 | 合格标准 |
|------|--------|---------|
| 准确性 | 设备数量 | 与户型匹配 |
| 准确性 | 电源冗余 | ≥20%冗余 |
| 完整性 | 回路分配 | 开关数=灯具分组数 |
| 完整性 | 窗帘电机 | 电机数=窗户数 |
| 合规性 | 报价模板 | 只改数量 |
| 合规性 | 网关覆盖 | 每层≥1个中枢 |
| 专业性 | 布线规范 | 强弱电分离 |

## HOLDING

- 只改数量，其他字段锁死
- 电源冗余计算：设备总功耗×1.2
- 每层至少1个网关/中控
- 强弱电分离布线
