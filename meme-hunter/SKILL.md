# 查网络热梗 · Chinese Meme Hunter

> 查中文互联网上的热梗、流行语、网络事件。搞清来源、含义、传播路径和用法。
> 任何 AI Agent 通用。

## 什么时候触发

当用户问到以下问题时，都应该触发此技能：

**直接问梗：**
- "XX是什么梗" / "XX是什么梗啊"
- "XX是什么意思" / "XX是啥意思"
- "XX是啥" / "XX是什么"
- "XX这个梗怎么来的"
- "XX的出处是哪里"
- "XX的梗出自哪里"
- "XX是什么情况"
- "XX怎么回事"

**问流行趋势：**
- "最近大家都在发XX，啥意思"
- "XX怎么突然火了"
- "XX为什么突然流行"
- "XX为什么火了"
- "XX怎么火起来的"
- "XX我刷到好多次了，什么意思"
- "XX在说什么"
- "XX为什么大家都在刷"
- "XX最近怎么这么火"

**求科普：**
- "XX是什么梗，求科普"
- "XX什么梗，求解释"
- "给我讲讲XX这个梗"
- "XX这个梗是啥"
- "不懂就问，XX是什么"
- "XX是什么意思，没看懂"
- "XX在说什么，谁来解释一下"
- "XX是什么梗，为什么大家都在说"

**问当前热梗（不需要具体关键词）：**
- "最近有什么热梗"
- "最近有什么梗"
- "最近有啥梗"
- "最近网上在流行什么"
- "最近大家都在玩什么梗"
- "最近有什么好玩的梗"
- "最近有什么网络热词"
- "最近什么梗比较火"
- "最近网上有什么新梗"
- "有什么新梗"
- "最近流行什么"

**变体模式：** 用户可能说"竹知了"、"竹知了是什么"、"竹知了什么梗"、"竹知了为什么火了"等，需要能识别出核心关键词（竹知了）并自动匹配到梗查询模式。

## 搜索引擎策略

搜索引擎（搜狗/Bing/DuckDuckGo）反爬严重，优先使用**直接抓取热榜页面**的方式。

### 直接热榜数据源（优先）

当用户问"最近有什么热梗"时，直接抓取以下热榜页面，从中提取当前热门话题：

| 平台 | 热榜地址 | 获取方式 |
|------|----------|----------|
| **微博热搜** | `https://weibo.com/ajax/side/hotSearch` | 需带 Cookie，JSON 格式 |
| **百度热搜** | `https://top.baidu.com/board?tab=realtime` | 浏览器抓取 HTML |
| **知乎热榜** | `https://www.zhihu.com/hot` | 浏览器抓取 HTML |
| **B站热门** | `https://www.bilibili.com/v/popular/rank/all` | 浏览器抓取 HTML |

| **豆瓣** | `https://www.douban.com/group/explore` | 浏览器抓取 HTML |

## 输出格式

每个梗的解释必须包含以下四要素：

### 1. 来源（出处）
- 从哪个平台/事件出来的
- 什么时间开始的
- 最早是谁发的/哪个事件引发的

### 2. 含义
- 字面意思是什么
- 实际在表达什么
- 怎么用，在什么场景下用

### 3. 传播路径（为啥火）
- 为什么突然火了
- 有没有关键事件/人物推动
- 有没有争议/反转/投诉下架等戏剧性情节

### 4. 用法示例
- 一句话举例怎么用
- 常见的回复/评论方式

### 示例输出

```
🎋 竹知了

📌 来源
- 起源于传统竹制玩具（竹蝉），一摇就发出蝉鸣声
- 2026年7月底短视频平台爆火，大量博主跟风拍摄
- 后因华为以"损害商誉"为由投诉下架相关视频

💡 含义
竹知了本身只是玩具，但这个梗现在用来讽刺"过度维权"和"企业滥用投诉机制"

🔥 为什么火
- 第一阶段：玩具本身好玩，自然流量
- 第二阶段：华为投诉下架 → 引发网友逆反心理
- 第三阶段：网友开始用各种东西模仿竹知了音效，玩梗出圈
- 结果：一个9.9元的玩具成了全网最快被下架的爆款

💬 用法示例
"你这也要投诉？你是竹知了派来的吧？"
发竹知了表情包/视频，调侃小题大做
```

## 处理流程

```
用户问梗
  ↓
提取关键词（如"竹知了"）
  ↓
搜索关键词变体（"竹知了 梗"、"竹知了 什么梗"、"竹知了 为什么火了"）
  ↓
搜狗 → Bing → DuckDuckGo 多引擎轮询
  ↓
多平台结果（微博/B站/知乎/小红书/新闻）
  ↓
交叉验证信息（确保不是谣言或误传）
  ↓
按四要素整理输出（来源/含义/传播路径/用法）
  ↓
如果信息不足，诚实地告诉用户"目前查到的信息有限"
```

## 注意事项

1. **梗的时效性极强** — 昨天的梗今天可能就过时了，每次都要重新搜索
2. **谐音梗/变体** — 注意关键词可能有不同写法，如"竹知了"也搜"竹蝉"、"yyds"也搜"永远的神"
3. **多源交叉验证** — 不要只信一个来源，对比微博/B站/知乎的说法
4. **敏感内容** — 如果梗涉及敏感话题，客观陈述事实，不站队不评价
5. **搜索引擎反爬** — 搜狗不行换Bing，Bing不行换DuckDuckGo
6. **诚实告知** — 如果搜不到或信息太少，别硬编，直接说"这个梗我查到的信息有限"
